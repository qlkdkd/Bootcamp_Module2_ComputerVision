# Opencv 시작과 이미지 구조

## 이미지는 숫자 배열이다
- 흑백 사진: np.uint8로 이루어진 2차원(가로, 세로) 배열
    - 배열의 값 하나는 0~255 사이의 정수 값
    - 값이 클 수록 하얀색에 가까워짐
- 컬러 사진: np.uint8로 이루어진 3차원(가로, 세로, 색상) 배열
    - 색상은 B(Blue), G(Green), R(Red)로 구성
- 오버플로우: uint8 자료형에서 값이 255를 초과하면 0부터, 0 보다 작으면 255부터 다시 돌아감
- 넘파이 배열로 영상 연산 가능

## 해상도와 좌표
- 해상도: 사진의 가로/세로 수
    - 같은 시야를 찍을 때 해상도가 높으면 픽셀 하나가 덮는 실제 크기가 작아져 작은 것도 보임
    
## 컬러와 채널
- 컬러 사진은 2차원 배열이 3개 들어있는 구조
- 타 프로그램(matplotlib, 딥러닝 등)에서는 R, G, B순서라 OpenCV에서 연산한 영상을 타 프로그램에 넘겨줄 때 순서를 바꿔줘야 함
- 검사 대부분은 흑백으로 하지만 색 관련 작업에선 반드시 컬러로 연산해야 함
- `cv.split(img)`: img를 파랑, 초록, 빨간색 별로 채널로 나눠줌 -> 배열 3개 반환

## 읽기와 저장
- `cv2.imread(경로)`: 경로에서 영상 불러오기
- `cv2.imwrite(경로, 저장할_이미지)`: 경로에다 이미지 저장

### 확장자별 특징
- jpg: 손실 압축으로 저장하며 용량이 작음. 대량 보관할때 사용
- png: 손실 없이 저장하며 용량이 큼. 학습 데이터나 측정용으로 사용. 보통 원본으로 사용
- bmp: 압축 없음. 장비 간 주고받을 때 사용

## 웹캠
- 컴퓨터에 연결된 카메라와 상호작용
- `cv2.VideoCapture(카메라_번호)`: 카메라_번호에 해당하는 카메라 불러오기
- `cv2.VideoCapture().read()`: 카메라 확인하기
